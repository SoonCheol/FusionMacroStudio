# Fusion Macro Studio
Fusion 360 전용 12키·3노브 매크로 키보드 정적 웹 편집기.
GitHub Pages: https://sooncheol.github.io/FusionMacroStudio/ (배포 설정/성공 확인 필요).
USB 514C:8842 전용. Chrome/Edge HTTPS에서 연결. Fusion 애드인은 별도 ZIP 설치 프로그램으로 구현(실기 미검증).
현재 v0.3.16: 메뉴 기반 명령 탐색, 드래그 매핑, 다크/라이트, JSON, 원본 PNG 폴더 불러오기, 제한된 HID 단일 키 읽기/쓰기. 실제 키보드 검증 전. 지원되는 키·미디어·마우스 백업 레코드 복원 대기 구현; LED·지연 및 미확인 유형 제외, 실기 미검증. 애드인은 프로필을 로컬로 가져오며 실제 Fusion 실행 검증 필요.
개발 지침 AGENTS.md, 상태 docs/CURRENT-STATUS.md, 출처 docs/SOURCES.md.

원본 PNG·가져온 카탈로그·미전송 변경은 브라우저에 로컬 보관. 장치 전체 읽기 후 원본 백업을 별도로 내려받을 수 있음.

쓰기 직전 원본 백업 저장. Actions의 validate 성공 시 웹/설치 패키지 아티팩트도 제공 (Pages 활성화와 별개).

웹 기본 아이콘은 독자 제작 CAD 벡터(핵심 개별, 기능군 공유). 로컬 원본 PNG가 우선. icons.html에서 메뉴 아이콘을 검토할 수 있음.

아이콘 갤러리: 공식 원본 참조 확인 63개, 미검수 263개. 참조 링크를 개별 확인할 수 있음. 원본은 재배포하지 않음.

독립 애드인 설치/프로필 검증 및 상태 표시 강화(v0.3.9), 실기 확인 전.

실기 테스트 절차: docs/DEVICE-TEST.md. 실제 키보드 없이 수행하는 모의 HID 테스트와 JS/Python 매핑 교차 검사를 추가함.

고정 명령 코드(v0.3.16): 공개 편집기에서 새 배정은 키보드에 명령별 고정 코드 직접 저장, 대응 애드인이 프로필 갱신 없이 실행. 1220개 등록 ID, 14641개 코드 용량. 로컬 편집기는 기존 호환 방식 유지. 새 연속 입력 실기 검증 전이며 기존 설정 자동 변환 없음.

현재 v0.3.17: v0.3.16 직접 코드 실기 성공(사용자 보고). 시점 명령 신규 배정은 2단계 코드, 이전 5단계 호환. 자동 바디 중심, 회전 중심 모드 명령, 가속·동일 방향 묶음, 노브 누름 전환 시험 기능, 레이어/전체 지우기 대기 추가.

v0.3.18: 노브별 슬라이드 전환 후 일반/누른 채 좌우 시점 명령 직접 드래그 등록. 실제 회전 레코드에 두 명령 저장, 누름 감지 자동 등록. 실기 검증 전.

v0.3.19: 누른 채 회전 드래그 시 고정 코드표 실행 명령 지원, 변환 불가 원시 키는 명시적 교체 확인, 드롭 오류 안내. 실기 검증 전.

v0.3.21: 로컬 편집기 상단 애드인 버전/업데이트 확인 및 설치 예약. 최신 ZIP 자동 다운로드·SHA256 검증 후 Fusion 종료 대기, 기존 설치기의 백업·교체 기능 사용. 완료 알림 후 Fusion 수동 재실행. 최초 0.3.21은 기존 설치기로 설치 필요.

v0.3.22: DeckForge 방식 참고. 다운로드 진행률, SHA256 검증 ZIP 재사용, 최신·직전 ZIP 보존, 다운로드 후 설치/나중에 확인, 정상 창 닫기 요청(강제 종료 금지), 설치 완료 후 기존 Fusion 실행 파일 재실행 요청. 수동 종료/재실행 대체 경로 유지.

## Windows 독립 편집기 (v0.4.0)
공개 웹은 키보드 설정 전용입니다. Windows 편집기는 Fusion이 꺼져 있어도 작동하며 닫으면 종료됩니다. 애드인 설치/업데이트와 편집기 업데이트는 Windows 앱에서 처리합니다. 기존 애드인/프로필 유지. Windows NSIS 설치기 및 업데이트 메타데이터는 Pages CI에서 생성합니다. 실제 Windows/USB 검증 필요.
