# Fusion Macro Studio
Fusion 360 전용 12키·3노브 매크로 키보드 정적 웹 편집기.
GitHub Pages: https://sooncheol.github.io/FusionMacroStudio/ (배포 설정/성공 확인 필요).
USB 514C:8842 전용. Chrome/Edge HTTPS에서 연결. Fusion 애드인은 별도 설치 예정.
현재 v0.1.0: 메뉴 기반 명령 탐색, 드래그 매핑, 다크/라이트, JSON, 원본 PNG 폴더 불러오기, 제한된 HID 단일 키 읽기/쓰기. 실제 키보드 검증 전. 전체 원본 프로필 복원 및 애드인 실행 아직 미지원.
