# Fusion Macro Studio
Fusion 360 전용 12키·3노브 매크로 키보드 편집기 (독립 Windows 앱).

대상: USB HID 514C:8842. 기존 펌웨어 유지.
기존 Fusion Command Manager의 명령 카드 탐색 UI를 재활용하고, Macropad Rebind의 통신 구현을 참조한다.
명령을 키/노브에 드래그해 배치하고 Fusion 애드인이 실행하도록 개발한다.

현재는 개발 준비 단계이며 실행 가능한 설치 파일은 아직 없다.
