장치 통신 기록
연결 후 읽기 전까지 버튼은 비어 있습니다. 쓰기: 변경한 슬롯만 전송 후 재읽기. 공개 편집기의 새 배정은 키보드에 직접 저장. 로컬 호환 편집기는 기존 프로필 자동 반영. 저장: 프로필 JSON 백업. 불러오기: 프로필 또는 장치 백업 JSON. 읽기 후 쓰기 버튼으로 적용합니다. LED·지연은 복원 대상이 아닙니다.
