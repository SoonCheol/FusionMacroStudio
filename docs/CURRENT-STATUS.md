- Pages workflow 등록, 실제 Pages 활성화/배포 결과 별도 확인 필요.
- 애드인: 프로필 가져오기, 로컬 상태, 설치/제거, Fusion API 명령/설명 및 접근 가능한 원본 PNG 내보내기. Pages workflow에서 설치 ZIP 생성. EXE 아닌 CMD+PowerShell GUI. 다운로드 실물/Pages 배포 및 Windows 실행 확인 전.
