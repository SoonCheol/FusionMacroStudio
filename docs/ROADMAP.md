# 개발 로드맵

사용자 지시: 현재 UI 및 아이콘 유지. 아이콘 재생성은 기능 개발과 통합 검증 이후 마지막에 수행.

1. 빌드/웹 안정화 (v0.3.8 검증 대기)
2. 키보드 연결·전체 읽기·안전한 변경 쓰기·재읽기 검증 (부분 구현, 실기 미검증)
3. 프로필 저장·불러오기 및 지원되는 레코드 복원 (v0.3.8 구현, 실기 미검증; 읽을 수 없는 LED/지연은 전체 복원으로 주장하지 않음)
4. 독립 Fusion 애드인 및 설치 프로그램 (v0.3.9 보완, Windows/Fusion 실기 검증 전)
5. Fusion 명령 및 노브 시점 제어, 길게 ESC
6. USB/Bluetooth 실제 키 입력 및 통합 검증
7. 마지막 제작 작업: 기존 미검수 아이콘 개별 원본 대조 및 재생성
8. 정식 v1.0.0 배포
