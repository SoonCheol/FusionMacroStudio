# 실기 검증 안내 (v0.3.16)

자동 검사는 실제 키보드·Fusion 실행을 대신하지 않는다. 아이콘 재생성은 마지막 단계로 유지한다.

## 1. 설치 확인
- Pages에서 애드인 ZIP을 다운로드하고 압축 전체를 해제한다.
- Fusion 종료 후 Setup.cmd 실행, Install / update add-in. 기존 DeckForge는 변경하지 않는다.
- Fusion 시작 후 설치 프로그램 상태에서 Installed, Running을 확인한다. 기존 개인 프로필이 있으면 먼저 별도 보관한다.

## 2. 읽기와 백업 (변경 없음)
- 키보드를 USB로 연결, 웹 편집기에서 연결 → 읽기.
- 3개 레이어 21개씩, 63/63 확인. 최근 읽기 백업 JSON을 별도 보관한다.
- 63개 미만이면 쓰기 금지. 사용자 환경에서 최초 버튼/노브 방향이 일치하는지 확인한다.

## 3. 버튼 한 개만 변경
- 테스트용 빈 Fusion 문서에서 쓸 명령(스케치 선 등)을 선택한다. 사용하지 않는 슬롯 하나에만 배정한다.
- 미전송 변경 1개 확인. 쓰기, 변경 확인 및 전체 재읽기. 쓰기 직전 백업도 보관한다.
- 저장한 웹 프로필 JSON을 Setup에서 가져오고 Running / Profile loaded / 1 mapping 확인(다른 기존 매핑이 있으면 그 수를 반영).
- 물리 레이어를 일치시킨 뒤 스케치 편집 상태에서 짧게 눌러 명령 시작 확인. 0.7초 이상 길게 눌러 취소가 한 번만 발생하는지 확인. 일반 키보드와 동일 F13~F24 조합을 구별할 수 없는 제한이 있음.
- 길게 누름이 불가능하면 장치가 짧은 키 펄스만 내보내는지 확인해야 한다. 지원을 추측하지 않는다.

## 4. 노브 및 복원
- 이후 별도로 노브 좌/우에 줌 또는 오비트를 등록하고, 한 스텝씩 방향·속도 확인. 누른 채 회전은 별도 하드웨어 이벤트가 있는지 확인 전 미지원.
- 원본 장치 백업으로 복원할 때는 불러오기 → 읽기 → 쓰기. 변경 개수와 재읽기를 확인한다. 장치 백업에는 Fusion 명령 ID, LED와 지연 상태가 없으므로 필요하면 별도로 기존 웹/애드인 프로필도 복구한다.
- USB 테스트 성공 후 Bluetooth 실제 입력을 확인한다. USB 통신 및 Windows/Fusion 실기는 모두 사용자 장치에서 수행한다.

## 자동 동기화 (v0.3.16)
Fusion 실행 후 Chrome/Edge에서 http://127.0.0.1:18472/ 접속. 기존 프로필 자동 표시, 연결→읽기→변경→쓰기. 화면에서 Fusion 자동 반영 및 매핑 수 확인. 저장/가져오기 불필요. Pages는 수동 모드. 기존 Pages에만 남은 변경은 백업 JSON을 로컬 편집기로 한 번 옮기거나 재배정한다.

## 팬 및 노브 조합 진단
- 팬은 시점 제어에서 4방향 중 원하는 명령을 배정하고 쓰기. 모델 형상 변경 없이 화면 이동 방향 및 거리 확인.
- 노브의 누르기 및 좌우 회전 모두 Fusion 명령 배정 후 로컬 편집기 '노브 누른 채 회전 진단'에서 30초 진단 시작. Fusion에서 누름→유지→회전→뗌. 브라우저로 복귀해 이벤트 순서 확인. 누름 down과 up 사이에 회전 이벤트가 들어오는지 확인해야 조합 동작 구현 여부 판단 가능. 진단은 실제 명령 동작을 유지하며 일반 키는 수집하지 않음.

## 고정 명령 코드 실기 (v0.3.16)
공개 Pages에서 연결→읽기(63/63)→빈 슬롯 1개에 명령 등록→쓰기. v0.3.16 애드인 실행 중 Fusion에서 짧게 누름. 프로필 저장/가져오기 없이 실행되어야 함. 같은 슬롯 다른 명령으로 쓰고 다시 실행. 읽기 시 코드로 명령 복원 확인. 기존 로컬 호환 매핑은 그대로 사용 가능. 직접 코드는 Ctrl+F24 및 Ctrl+F13~F23 4자리만 예약; 연속 입력 전송과 길게 누르기/노브 속도 실기 미검증. 실패하면 자동 전환 금지, 쓰기 직전 백업 복원.

- 웹 1: 접속/연결만으로는 모든 키와 노브 동작 칸이 비어 있어야 함. 전체 읽기 성공 후에만 장치 데이터 표시, 연결 해제하면 다시 빈 상태. 공개 편집기는 기존 위치별 키값을 실제 명령으로 추정하지 않음.

## v0.3.17
애드인 업데이트 후 기존 배정으로 자동 피벗 및 가속 확인. 노브 시점 명령 재배정/쓰기 시 2단계 코드 적용. 누르기 슬롯에 '누른 채 회전: 팬' 또는 '누른 채 회전: 상하' 등록(짧은 누르기 없음), 해당 노브 좌우에 오비트 명령 재배정해 짧은 코드를 적용. 누른 상태에서 좌우 회전 및 떼고 일반 회전 확인. 실패 시 로컬 편집기 30초 진단에서 marker down/up 사이 decoded 이벤트 확인. 동시에 다른 노브를 돌리면 구별 불가. 레이어/전체 지우기는 실제 쓰기 전 확인하며 쓰기 직전 백업으로 복구 가능 범위 확인(미확인 종류/LED/지연 제외).

## v0.3.18
노브 일반 좌우에 오비트 명령 등록 후 스위치를 누른 채로 전환. 좌우 각각 다른 시점 명령 드래그(예: 위 오비트/아래쪽 팬), 누름 감지 자동 등록 확인. 쓰기 후 읽기, 스위치 양쪽 표시와 실제 일반/누른 채 회전 검증. 애드인 0.3.18 필요. 누름 신호가 유지되지 않으면 누른 채 동작 불가하며 로컬 편집기 진단에서 marker down/up 및 decoded 순서 확인. 짧은 누르기 별도 명령은 현재 함께 지원하지 않음.

## v0.3.19
누른 채 좌우에 고정 코드표 내 일반 실행 명령도 드래그 가능. 원시 F키가 일반 회전에 남아 있으면 확인 후 해당 일반 회전을 미설정으로 변경한다. 시점 제어 11개 조합은 기존 4단계, 기타 조합은 14단계 코드. 쓰기·다시 읽기 후 일반/누른 채 표시 및 실제 Fusion 동작 검증. 애드인 0.3.19 필요. 짧은 누르기 별도 명령과 누름 유지 실기 검증은 남아 있음.

## v0.3.20
기존 키보드 설정 그대로 애드인 업데이트. 일반 회전, 누른 채 연속 회전, 회전 중단 500ms 이상 후 일반 회전, 다른 노브 일반 회전 확인. 진단 decoded에 held-grace/held-physical/normal 표시 확인. 유예 300ms/500ms는 실제 진단에 기반한 추정 방식이며 물리 해제 시점 정확히 구별하는 것은 아님.
